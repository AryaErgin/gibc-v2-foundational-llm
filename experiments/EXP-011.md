# EXP-011 — Recipe v3 Long-Horizon Calibration

## Scientific question

How does the frozen selected near-cap Recipe v3 train through the first 1.5B prediction tokens when the complete 45,777-update cosine schedule is fixed from initialization?

## Selected architecture and controls

EXP-010A produced a valid engineering-tie result and retained Recipe v3. EXP-011 therefore uses exactly 49,860,480 trainable parameters: vocab 8,192; d_model 640; 9 layers; 20 heads x 32; SiLU-gated SwiGLU d_ff 1,728; tied embeddings/output; RMSNorm; RoPE; causal MHA; no bias/dropout. It starts from a fresh seed-42 initialization and never resumes an EXP-008/009/010 checkpoint.

Data Recipe v1 remains deterministic, globally content-hash deduplicated and contamination screened at the fixed 2:1 FineWeb/FineWeb-Edu mixture. Context is 512; physical batch is 32 sequences x 2 accumulation; effective prediction tokens/update are 32,768; BF16 autocast retains FP32 parameters/optimizer state; AdamW uses beta1/beta2/eps 0.9/0.95/1e-8 with matrix weight decay 0.1; gradient clipping is 1.0; peak/min LR are 6e-4/6e-5; warmup is 100 updates. Native Windows, OMEN Performance mode, and AC power are frozen system controls.

## Horizon and data gates

The cosine horizon is exactly 45,777 updates from step zero. The hard ceiling is 1,500,020,736 prediction tokens. The first phase uses only the existing EXP-006 900,071,424-token artifact, after independently verifying its manifest/hash and its exact 300,023,808-token EXP-004 prefix. At step 27,468, a deterministic EXP-011 artifact is required before resume. Its first 900,071,425 stored uint16 token IDs / 900,071,424 prediction tokens must be byte-identical to EXP-006; its first 300,023,809 stored IDs must remain byte-identical to EXP-004. Failure of either raw-byte prefix gate stops training.

Validation/checkpoint milestones are step 9,156 (300,023,808 tokens), 18,312 (600,047,616), 27,468 (900,071,424), 36,624 (1,200,095,232), and 45,777 (1,500,020,736). General, Edu, and combined validation are recorded at each. The 300M checkpoint is not a reproduction of EXP-008 because the schedule horizon differs.

## Abort conditions and authorization

Stop and preserve evidence on any parameter/hash/prefix/manifest failure, non-finite loss or gradient, incorrect checkpoint/RNG/optimizer/cursor resume, required checkpoint/validation omission, unexpected Windows/PyTorch/environment/Performance/AC change, or severe validation regression suggesting corruption. No official benchmark, architecture/LR/data/batch/context/precision change, pretrained weights, security weakening, or training past 1.5B is permitted.

The research authorization permits this single controlled run only after the EXP-010 decision is valid and all preflight gates pass.
