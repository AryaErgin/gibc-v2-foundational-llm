# EXP-003 — FineWeb-Edu Data-Quality Ablation

## Question

At fixed architecture, tokenizer, initialization seed, optimizer, context, batch, token budget, and 9,156-step cosine schedule, does standard FineWeb-Edu improve educational-language modeling without materially degrading general-language modeling relative to EXP-002?

## Fixed controls

EXP-003 uses the exact 8,392,960-parameter decoder, seed 42, 512-token context, BF16 autocast with FP32 parameters, AdamW (.9, .95, 1e-8), 0.1 matrix-only decay, LR 6e-4 to 6e-5, 100 warmup steps, clipping 1.0, 32,768 prediction tokens/update, physical microbatch 32, accumulation 2, 9,156 updates, and 300,023,808 prediction tokens. The frozen byte-level BPE tokenizer is `artifacts/exp001c-full/tokenizer/tokenizer.json`, SHA-256 `c5592fba176c3d2f7915a3812559a24d7a669206f4a22484b053c8a9ce08be14`; it is never retrained.

The only intended intervention is the accepted training-data source: standard `HuggingFaceFW/fineweb-edu` at immutable revision `87f09149ef4734204d70ed1d046ddc9ca3f2b8f9`, config `default`. FineWeb-Edu is filtered public FineWeb content, not synthetic training text. Its educational classifier was trained using annotations generated by Llama-3-70B-Instruct; this project neither created that filter nor authorizes synthetic teacher completions. The recorded dataset license is ODC-BY.

## Validation protocol

`general_validation` is the exact frozen EXP-001/002 FineWeb tensor: inputs SHA-256 `f721fda2a0a0ca11a580178dba6c2592af4dd9324da3ed7120624b7364d653f7`; targets SHA-256 `2ca518affa0b36d15c7c427de84b4c7d761926e1e993c03724d75f396934f13e`. `edu_validation` is a distinct deterministic content-hash validation split from the pinned FineWeb-Edu stream, screened with the same public-split normalized 13-gram contamination index and packed to exactly 131,072 prediction tokens.

Before EXP-003 training, the final frozen EXP-002 checkpoint must be evaluated on `edu_validation`. That result is a new-corpus internal validation baseline, not an official benchmark result. Internal validation is predeclared at steps 0, 3,052, 6,104, and 9,156 on both validation tensors. No official benchmark task is part of this experiment.

## Decision criteria

The primary outcome is held-out validation loss. FineWeb-Edu is a strong final-data candidate if educational validation meaningfully improves against the frozen EXP-002 checkpoint while final general FineWeb validation is no more than 0.05 nats worse than EXP-002's 3.8954159319400787. A substantially improved educational result with a general-validation regression over 0.05 nats would motivate a separately authorized mixed-data experiment; no mixture is selected here.
