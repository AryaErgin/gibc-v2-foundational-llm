# EXP-004 — Mixed FineWeb / FineWeb-Edu Data Ablation

## Question

At the fixed 8,392,960-parameter architecture and 300,023,808-prediction-token horizon, can a roughly 2:1 unique-document FineWeb:FineWeb-Edu mixture retain general-language quality while capturing a meaningful portion of FineWeb-Edu's educational-language benefit?

## Controlled intervention

All EXP-002/003 model, tokenizer, initialization, optimizer, schedule, context, seed, effective batch, and physical batch controls remain fixed: seed 42; context 512; microbatch 32; accumulation 2; 9,156 updates; 100 warmup steps; and cosine decay through step 9,156. The only intervention is training-data composition.

The deterministic target is 200,015,872 FineWeb and 100,007,936 FineWeb-Edu prediction tokens, totaling 300,023,808. The builder chooses whole documents by a deterministic token-deficit schedule, breaks ties in favor of FineWeb, and records the actual source prediction-token contribution. Every selected document is keyed by canonical content SHA-256 in a global set shared across both streams; a document already selected from either source is never emitted from the other. This is educational up-weighting of unique documents, not duplicate repetition.

FineWeb is pinned to `HuggingFaceFW/fineweb`, `sample-10BT`, revision `9bb295ddab0e05d785b879661af7260fed5140fc`; FineWeb-Edu is pinned to `HuggingFaceFW/fineweb-edu`, `default`, revision `87f09149ef4734204d70ed1d046ddc9ca3f2b8f9`. Both source streams use the existing public-split normalized 13-gram contamination screen. No benchmark task is evaluated during this experiment.

## Frozen validations

`general_validation` remains the exact EXP-001/002 tensor: inputs SHA-256 `f721fda2a0a0ca11a580178dba6c2592af4dd9324da3ed7120624b7364d653f7`; targets SHA-256 `2ca518affa0b36d15c7c427de84b4c7d761926e1e993c03724d75f396934f13e`. `edu_validation` is the exact EXP-003 frozen tensor: inputs SHA-256 `cc75580b854b69846b1ff15385fbb87adf5bdf1701c1bfe9e8e8d5fdb651fb1a`; targets SHA-256 `300608bc74e052f1580d78e3ad5e1174312360a766f3278c6ce2bdf3336a48b4`.

Both internal validations are predeclared at steps 0, 3052, 6104, and 9156. The strong-outcome thresholds are fixed before training: general loss <= 3.9454159319400787 and educational loss <= 3.708632768392563. These are project decision thresholds, not statistical claims.
